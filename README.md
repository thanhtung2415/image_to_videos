# Image To Videos

Website chuyen anh thanh video ngan theo SRS v2.0.

## Kien truc

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Storage: local trong giai doan dev, co san cau hinh Cloudinary
- Video engine MVP: FFmpeg

## Chay local

```bash
npm install
npm run dev:backend
npm run dev:frontend
```

Tao file `.env` trong `apps/backend` dua tren `.env.example`.
